# 모기 없는 밤 · 연못 수비대

알과 유충이 자라는 연못에서 **괴물로 진화하는 모기에게 맞서는 무한 생존 게임**입니다. 고정된 승리 시간은 없습니다. 22초마다 단계가 올라가며 부화 속도·증원량·변이 등급이 증가하고 새로운 장비가 해금됩니다.

성충의 **위험도 합계가 30 이상**이면 붕괴 게이지가 쌓여 5초에 패배합니다. 위험도를 낮추면 초당 2초씩 회복됩니다. 퇴치 점수·생존 시간·도달 단계로 기록에 도전하세요.

HTML, CSS, Canvas 2D, JavaScript ES modules만 사용합니다. 빌드·패키지 설치·백엔드·API 키가 필요하지 않습니다. 모든 그래픽은 코드로 직접 그리며, 음향은 Web Audio로 생성합니다. 글꼴만 Google Fonts에서 선택적으로 불러오며 연결되지 않아도 시스템 글꼴로 동작합니다.

## 로컬 실행

Node.js 18 이상에서:

```sh
npm run dev
```

브라우저에서 <http://127.0.0.1:4173>을 여세요. ES modules를 사용하므로 `index.html`을 파일로 직접 여는 대신 HTTP 서버를 사용해야 합니다. 의존성 설치는 필요하지 않습니다.

```sh
npm run check
npm test
```

## 조작

- PC: 클릭 또는 드래그. **1–9, 0, -, Q, W, E, R**로 무기 선택.
- 모바일: 무기를 누른 뒤 연못을 터치하거나 드래그.
- **P / Esc**: 일시정지·계속하기. 탭 전환·창 포커스 이탈 시 자동 정지.
- 상단 **♪**: 배경음·효과음 켜기·끄기. 게임 시작 시 켜지며 이전 설정을 기억합니다.
- 최고 점수·최고 단계·최다 퇴치 수는 해당 브라우저에 저장됩니다. 저장을 차단한 환경에서도 게임은 실행됩니다.

장비는 총 15종입니다. **소용돌이 → 부적 → 번개**로 연쇄 폭발을 일으키거나, 시간 되감기로 위험도를 낮춘 뒤 유충을 정리하세요. 미꾸라지는 다른 먹이를 분담하고 서로 간격을 유지합니다. 위 표의 범위 값은 화면 해상도와 무관한 게임 좌표 기준입니다.

잠긴 무기는 게임 판정에서도 차단합니다. 매 판 해금 상태는 초기화됩니다. 성충은 살아남으면 15초마다 다음 등급으로 진화합니다. 진화할 때 받은 피해 비율은 유지됩니다. 얼려두면 진화도 멈춥니다. 자연 진화는 W1~2에서 흡혈종, W3~4에서 철갑종, W5~7에서 사신종까지 가능하며 여왕은 W8부터 나타납니다. 단계 상한에 도달한 적은 진화 시간을 미리 쌓지 않습니다.

| 변이 | 체력 | 위험도 | 특징 |
|---|---|---|---|
| 일반 모기 | 2 | 1 | 뜰채 두 번으로 처치 |
| 흡혈종 | 5 | 2 | 이동 속도 증가 |
| 철갑종 | 11 | 3 | 커진 몸집과 장갑 |
| 사신종 | 20 | 5 | 빠른 이동, 8.5초마다 유충 2마리 생성 |
| 재앙의 여왕 | 65 이상 | 10 | 거대한 보스, 8.5초마다 유충 4마리 생성 |

W8부터 4단계마다 여왕이 추가 등장하며 후반 여왕의 체력은 계속 증가합니다. 절대 영도·여래신장을 먼저 확보하고, 용왕이 열리는 W8에서 첫 여왕과 맞서도록 구성했습니다. W10 이후에도 증원과 단계 상승이 이어집니다. 화면의 체력 막대와 색상으로 변이를 구별하세요. 생물과 무기의 효과는 게임을 위한 과장 설정입니다.

## GitHub Pages 배포

### 방법 A — 브랜치에서 바로 배포 (가장 간단)

1. GitHub에서 저장소를 만들고 이 폴더의 파일을 `main` 브랜치에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. 브랜치를 **main**, 폴더를 **/(root)**로 설정하고 저장합니다.
4. 배포가 완료되면 `https://계정.github.io/저장소이름/`으로 접속합니다.

이 방법을 사용할 때는 `.github/workflows/deploy.yml`을 저장소에 포함하지 않거나, Actions 탭에서 해당 사용자 정의 워크플로를 비활성화하세요. 아래 방법 B와 동시에 설정할 필요는 없습니다.

### 방법 B — 테스트 후 자동 배포

`.github/workflows/deploy.yml`이 포함되어 있습니다.

배포 워크플로는 [GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)를 참고했습니다.

1. GitHub에서 저장소를 만들고, **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다.
2. 프로젝트를 `main` 브랜치에 올립니다.
3. **Actions → Deploy game to GitHub Pages**에서 실행 상태를 확인합니다. 최초 업로드 후 Pages 설정을 바꿨다면 **Run workflow**로 다시 실행하세요.
4. 문법 검사와 게임 규칙 테스트가 통과하면 정적 파일만 자동 배포됩니다.

로컬 폴더를 새 저장소에 올리는 예시:

```sh
git init
git add .
git commit -m "Build pond defense game"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git
git push -u origin main
```

실제 계정과 저장소 이름으로 바꿔 실행하세요. GitHub 저장소 생성·로그인·실제 게시 과정은 프로젝트 파일에 포함되지 않습니다. Pages 사용 가능 여부는 저장소 공개 범위와 GitHub 요금제에 따라 달라질 수 있습니다.

## 코드 구조

- `src/core.js`: 성장·부화, 무기 판정, 아군 사냥, 위험도, 승패. 브라우저 없이 테스트 가능.
- `src/game.js`: Canvas 그래픽, 파티클, 효과음, 입력, 화면 전환.
- `style.css`: PC·모바일 레이아웃.
- `test/core.test.js`: 장비 잠금·해금, 진화·체력·증식, 아군 배치 제한, 무기 조합, 지연 폭발, 위험도 회복, 무한 생존, 재시작 검사.
- `scripts/serve.mjs`: 로컬 개발용 정적 서버.

난이도는 `src/core.js`의 `THREAT_LIMIT`, `WAVE_SECONDS`, `EVOLUTIONS`, 생성 주기 및 `WEAPONS`의 해금 단계·피해·재사용 시간으로 조절할 수 있습니다.

## 공유와 괴물 도감
- 상단 `공유`에서 게임 주소를 복사합니다. 지원되는 브라우저에서는 다른 앱으로 공유할 수도 있습니다.
- localhost 주소는 다른 컴퓨터에서 열 수 없습니다. GitHub Pages 배포 주소에서 공유 버튼을 사용하세요.
- 장비 목록 아래 `괴물 도감`에서 8종의 외형과 등장 단계를 볼 수 있습니다. W1부터 두 종류가 등장하며 W6까지 새 종류가 합류합니다.
- 외형별 날갯짓·촉수·낫팔 애니메이션이 다릅니다. 전투 수치와 이동 속도는 기존 진화 등급을 따릅니다.
- 공유창과 도감을 여는 동안 게임은 정지하며, 원래 진행 중이었다면 닫을 때 재개됩니다.

## 사운드와 필살기
- 게임 시작 클릭 후 합성 배경음과 효과음이 재생됩니다. 단계가 오르면 음악 템포와 악기가 늘고 위험 시 경고음이 섞입니다.
- 상단 ♪ 버튼으로 전체 소리를 켜거나 끄며, 설정은 저장됩니다. 일시정지 중에는 소리가 멈춥니다.
- 용왕 강림: 긴 비늘 몸통, 뿔, 갈기, 수염, 발톱, 여의주와 물살 연출.
- 천뢰난무: W11 해금, R 선택 후 클릭. 물속·공중 전체 적에게 피해 24, 재사용 45초. 빙결 피해 보너스 적용.

## 단계별 강화와 연속 처치
- W2, W5, W8…마다 무작위 강화 세 가지 중 하나를 선택합니다. 선택 중에는 게임이 정지합니다. `나중에 선택`한 보급은 장비 목록 아래에서 다시 열 수 있습니다.
- 강화 8종: 강철 그물, 재장전의 달인, 특공대 훈련, 연못의 분노, 극저온 연료통, 괴수 사냥꾼, 빙결 공명, 연못의 가호. 강화는 해당 판에만 적용되며 종류별 중첩 상한이 있습니다.
- 4초 이내에 이어 처치하면 CHAIN이 쌓입니다. 12·24·36연속 처치마다 점수 +15와 공격 스킬 쿨다운 1초 회복을 받습니다. 뜰채·화염과 지원군 소환 쿨다운은 제외됩니다. 한 연속 처치 구간에서 보상은 세 번까지입니다.
- 여왕의 정기 출현 6초 전에 경고합니다. 연못의 가호는 한 판에 한 번 붕괴를 막고 전장을 3초간 얼립니다.
- 화염은 누르는 시간에 비례해 초당 피해 16을 줍니다. 기본 연속 분사는 약 4초이며 연료통 강화로 더 오래 유지됩니다.
- 모바일은 연못 안에서 스크롤·텍스트 선택을 막고, 연못 밖에서 장비 목록과 설명을 스크롤할 수 있습니다.

## 배포 파일 생성
`npm run build`는 `_site/`에 정적 파일만 생성합니다. 파일 내용으로 계산한 버전 번호를 CSS·진입 스크립트·모듈 주소에 붙여 배포 후 예전 파일과 새 파일이 섞이지 않게 합니다. GitHub Actions는 검사와 테스트 후 이 디렉터리를 배포합니다.
